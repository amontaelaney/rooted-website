# Rooted Futures

A buildless visual hub for the Rooted vision: Roots → Water → Branching Paths → Experiences → Confluence → Contribution.

Open `index.html` with its adjacent `assets/` directory to view locally. No dependency installation or build is required. All original artwork is preserved byte-for-byte. The recovered `rooted-site-with-visuals.html` attachment was unavailable; the current repository and original local artwork served as references.

## What is included

- Six branching discovery streams, 14 staged ideas, search and stage filters.
- Independent, IFAD-inspired eight-week Food Systems Lab draft.
- OSU Extension resources, potential discovery-tour hosts, growing systems, land and geothermal research, five farm software candidates, inclusive education/workforce and enterprise concepts.
- Original artwork gallery, keyboard focus, skip link, reduced-motion support and an animation pause control.
- Responsive layouts for smaller screens; no remote fonts, libraries or image dependencies.

## Stages and edits

Inspiration means a possibility; Research means investigating fit; Planned means draft design work; Approved requires documented permission and a decision. No approved projects or confirmed partnerships are claimed. Cascade School District permission is required before school greenhouse construction or implementation. Record who approved a future initiative, its date, scope and conditions before changing its `data-status` and visible status label in `index.html`.

Edit discovery content directly in `index.html`. Search and filters run in the browser; they do not save changes or submit information. All ideas remain readable with JavaScript disabled. Historic `style.css` remains in the repository for reference; the new page uses embedded styles.

## Public publication

GitHub reported `has_pages: false` during the October 17, 2026 update. No working public deployment was verified.

1. Open https://github.com/amontaelaney/rooted-website/settings/pages while signed in as the repository owner.
2. Under Build and deployment, select **Deploy from a branch**.
3. Choose **main** and **/ (root)**, then **Save**.
4. Wait for GitHub's Pages deployment to finish. Use the **Visit site** link shown in Settings → Pages.
5. The expected address is https://amontaelaney.github.io/rooted-website/ . Treat it as live only after successful deployment and a browser check. Test it on a phone and check search, filters, the six stream links, artwork links and motion control.

If Pages cannot be enabled, upload this directory as a static site to a host of your choice. Do not use an HTML-preview proxy as the permanent address.
